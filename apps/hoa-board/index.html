Violation reporting built for someone walking a property rather than sitting at a desk. Open the app on arrival and the address is already filled in.

Location is captured the moment you arrive, so you never type another street address in the field. Category, severity and photos, filed in under a minute.

One-tap address discovery

Scans Apple Maps and probes GPS offsets to find every residential address within a radius you set — a whole community imported in seconds.

A workflow with an audit trail

Open → Noticed → Warned → Fined → Resolved, every status change timestamped and logged, so a board has a record it can stand behind.

Automatic owner lookup

Connect a Regrid API token and one tap pulls the property owner from public records.
